# AI Marketplace Skills

Browse and install AI Marketplace skills directly in VS Code.

## Features
- Sidebar with Installed and Available skills
- One-click install — writes `SKILL.md` to `~/.copilot/skills/<name>/`
- `@marketplace` chat participant for list / install / help / search

## Settings
- `aiMarketplace.apiUrl` — registry API base URL (default `http://localhost:7071/api`)
- `aiMarketplace.githubRepo` — `owner/repo` fallback when the API is unreachable
